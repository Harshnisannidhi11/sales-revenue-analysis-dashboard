
# Sales & Revenue Analysis Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyze sales and revenue performance using the Superstore dataset.

## Objectives
- Analyze overall sales and revenue trends.
- Track key performance indicators (KPIs).
- Identify top-performing product categories and regions.
- Explore business insights through interactive filters and slicers.

## Tools Used
- Microsoft Power BI
- Excel
- Data Visualization
- Data Analysis

## Dataset
Superstore sales dataset containing information about orders, products, sales, profit and geographical regions.

## Dashboard Features
- KPI cards
- Sales and revenue analysis
- Interactive charts
- Filters and slicers
- Category and regional performance analysis

## Files Included
- Power BI dashboard (.pbix)
- Superstore dataset
- Dashboard screenshot

## Outcome
Created an interactive dashboard to explore sales performance and support data-driven business insights.
